# SB선보 복지 챗봇 음성 입력·답변 운영 가이드

## 1. 음성 입력

사용자는 복지 Q&A 화면 하단의 `🎙️ 음성` 버튼을 눌러 질문할 수 있습니다. 브라우저가 음성 인식을 지원하지 않으면 안내 메시지를 표시합니다.

음성 인식 후에는 곧바로 질문하지 않고 `인식 원문`과 `확인 문장`을 보여줍니다. 사용자는 다음 중 하나를 선택합니다.

- `이 내용으로 질문`: 확인 문장 그대로 전송
- `수정 후 질문`: 입력창에서 문장을 수정한 뒤 전송
- `취소`: 음성 입력 취소

## 2. 음성 인식 보정

다음 복지 제도명은 음성 인식 오류가 잦아 자동 보정합니다.

- 본인부담 의료비
- 자녀 대학 등록금
- 자녀 입학 축하금
- 복지수당
- 경조 휴가
- 장기근속
- 리프레쉬 휴가
- 워라밸
- 사우회
- 사내근로복지기금

## 3. 음성 답변

기본값은 `스피커 ON`입니다. 답변은 텍스트로 항상 제공되며, 스피커가 켜져 있으면 자동으로 음성 출력됩니다.

개별 답변 카드에서도 다음 버튼을 사용할 수 있습니다.

- `🔊 듣기`: 해당 답변 다시 듣기
- `⏹ 정지`: 음성 출력 중지

## 4. 남성·여성 음성 선택

사이드바의 `음성 성별`에서 여성 음성 우선 또는 남성 음성 우선을 선택할 수 있습니다. 단, 실제 남성/여성 음성 목록은 운영체제와 브라우저가 제공하는 음성 엔진에 따라 달라질 수 있습니다.

## 5. 답변 품질 기준

복지 규정에서 직접 근거가 부족하거나 질문 의도가 불명확하면 임의로 답하지 않고 다시 질문을 요청합니다. 예를 들어 `지원금 얼마야`처럼 제도명이 빠진 질문은 `자녀 대학 등록금 지원 기준 알려줘`처럼 구체적으로 다시 질문하도록 안내합니다.
