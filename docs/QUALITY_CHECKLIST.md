# 운영 품질 점검표

## 답변 품질

- [ ] 답변에 출처 제도명과 페이지가 표시되는지 확인
- [ ] 미매칭 질문은 관리자 분석에서 보완 대상에 표시되는지 확인
- [ ] 복지수당, 장기근속, 경조금 등 금액성 항목은 규정표와 일치하는지 확인
- [ ] 개정 PDF 업로드 후 기존 질문의 답변이 바뀌는지 확인

## TTS

- [ ] Windows Chrome에서 듣기/정지 확인
- [ ] Android Chrome에서 듣기/정지 확인
- [ ] iPhone Safari에서 버튼 클릭 후 듣기 확인
- [ ] 장문 답변이 문단 단위로 끊기지 않고 재생되는지 확인

## 관리자

- [ ] admin / 1111 로그인 후 비밀번호 변경
- [ ] Excel 사용자 업로드
- [ ] 질문 유형 분석 확인
- [ ] PDF 업로드/OCR 처리 확인

## NAVER WORKS

- [ ] Callback URL 등록
- [ ] X-WORKS-Signature 검증 성공
- [ ] 사용자가 Bot에게 질문 후 답변 수신
